Unit 2 Mock Exam Key

Teacher copy. The trap each question repeats from the real exam is noted in grey.

Multiple choice

  1. C
    4x² − x³ = x²(4 − x), so 0 bounces (mult. 2), 4 crosses, and (x + 2)² bounces at −2. (4 − x) carries a negative, so the degree-5 leading term is negative: left up, right down. A has x to the first power (cross at 0), B has (x + 2) (cross at −2), D has a positive leading coefficient.
    Traps: common factor hiding in the expanded form; (a − x) flips the sign; squared factor given as an expanded trinomial.
  2. B
    12x⁶ − 75y² = 3(4x⁶ − 25y²) = 3(2x³ + 5y)(2x³ − 5y). Choice A multiplies out correctly but still has a common factor of 3 hiding in the first binomial.
    Traps: GCF first; "equal but not complete" choice; even exponents as perfect squares.
  3. A
    Bounce at −4 (squared), cross at 1, and (1 − x) makes the leading coefficient negative: left up, right down. C has the right zeros but the wrong ends (ignores the flip). B swaps the zeros. D swaps multiplicities and ends.
    Traps: sign flip from (a − x); match zeros, behavior, then ends.
  4. D
    The squared factor is the bounce, so c = 3. The other factor is the cross, so b = −7 because (x − (−7)) = (x + 7).
    Traps: sign of the zero vs sign in the factor; which letter is squared.
  5. B
    k = −3: f(−3) = 2(−27) − 5(9) + 4 = −54 − 45 + 4 = −95. Synthetic check: 2, −11, 33, −95. A comes from (−3)² = −9. C is f(3).
    Traps: plug in the opposite of the constant in the divisor; parentheses around negatives.
  6. C
    8T = O + 5M + P, then 8T − O − P = 5M, so M = (8T − O − P)/5. B forgets to divide by 5. D has the wrong sign. A swaps T and M.
    Traps: coefficient on the target variable; dividing the whole group; sign errors when moving terms.

Open response

7a) All five: x = −3, −1, 0, 1, 3. The graph crosses the x-axis at each one, so each has odd multiplicity (here each is 1, since h(x) = −x(x − 1)(x + 1)(x − 3)(x + 3)).
7b) h(−x) = −(−x)⁵ + 10(−x)³ − 9(−x) = x⁵ − 10x³ + 9x = −h(x), so h is odd.
7c) Odd degree, negative leading coefficient: limx→−∞ h(x) = ∞ and limx→∞ h(x) = −∞.
Traps: reasoning must mention crossing; justify with substitution, not just "all odd powers"; limit notation for both ends.
8) Degree 6, leading coefficient negative: both ends down. Bounce at −3 (mult. 2), cross at −1 (flat, mult. 3), cross at 2. y-intercept q(0) = −(9)(−2)(1) = 18. Curve not to scale.
Traps: add all multiplicities for the degree (2 + 1 + 3); leading sign from the outer negative; flat cross at the cubed factor.
9) Synthetic division by 3: 1, −13, 40, 0. x² − 13x + 40 = (x − 5)(x − 8). Other roots: 5 and 8.
Traps: remainder must be 0; factor the quotient; answer asks only for the other roots.
10) f: f(1) = 4, f(−2) = 8 + 2 + 3 = 13, so (4 − 13)/3 = −3.
g: (8 − (−4))/3 = 4. h: (−1 − 1)/(1 − (−2)) = −2/3.
Order, greatest to least: g, h, f. Rates: 4 > −2/3 > −3.
Traps: subtract in the same order top and bottom; −3 is steep but least; each function is given in a different form (formula, table, graph).
